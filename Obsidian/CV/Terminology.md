**Image Processing**: images are transformed in some type of way, often as a pre-processing step
**Image Analysis**: extraction of meaningful information from images, often leading to considereable reduction in data and more compact description of the image
**Scene Analysis and Image Understanding**: find connection between recognized objects and meaning for the user (i.e. semantic meaning)
**Pattern Recognition**: processing of pattern in e.g. images, speech or other signals, classification of simple patterns,  analysis of complex patterns
	**Pattern**: an elem of the problem area under consideration (e.g. image of an obj), is a function, e.g. speech signal f(t), gray image f(x,y)
	 ![[Pasted image 20261013145359.png]]
	 **Simple Pattern**: can be classified as a whole, class name sufficient as description, e.g. single spoken word, character recognition
	 **Complex Pattern**: classification as a whole not possible, class name insufficient, e.g. desc of street scene, CT scan interpretation
