**Jetbrains**: survey of 15509 developers
- 90% use coding agents at work at least weekly, 68% use them daily

**StackOverflow**: survey of 30903 participants, not all participants answered all questions
- 83% use at least one coding tool (n = 17464)
	- 66% use coding assistants
- 77% use coding agents daily (n = 14478)

**SonarSource 2026**: survey of 1149 participants
- 72% use AI coding tools daily

**SonarSource 2027**: survey of 1026 participants
- 85% use AI coding tools daily
